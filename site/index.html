Install in 3 steps npm package

Install in 3 steps

Before you start: Node.js 22 or newer, and a phone on the same Wi-Fi as the computer. Type the package name exactly, with the @ and -g.

  1. Get Node.js

    Install the LTS version from nodejs.org, then open a new PowerShell window and check:

    node -v

  2. Install and check

    npm install -g @anisirji/pocket-dev
pocket-dev doctor

  3. Start and scan

    pocket-dev start

    Scan the QR code with your phone. Windows asks about the firewall: choose Private networks.

Full Windows guide and error fixes

Full macOS guide and error fixes

  1. Get Node.js

    nvm install 22
node -v

    Or use your package manager or nodejs.org.

  2. Install and check

    npm install -g @anisirji/pocket-dev
pocket-dev doctor

  3. Start and scan

    pocket-dev start

    Scan the QR code with your phone. If a firewall is on, allow TCP port 7777 from your local network.

Full Linux guide and error fixes (written from the code, not yet run on a real machine)

If you see unknown command 'start' or EEXIST: a different npm package called pocket-dev owns the command. Run npm uninstall -g pocket-dev, then install again.

What you get

  • Terminals

    Real shells that keep running when you close the page.

  • Chat

    Claude Code and Codex conversations, using your own logins.

  • Git and Files

    Browse, edit and commit on the computer where your work is.

  • Apps, health, power

    See open apps, battery and temperature, keep the machine awake.

  • Several computers

    One phone switches between your machines, with per-device permissions.

  • Internet access

    Optional, off by default, through a Cloudflare tunnel.

Security notes

  • It runs on your computer, as your user. There is no Pocket Dev cloud and no account.
  • A logged-in phone has the rights of your user: a shell, your files, and your Claude, Codex and GitHub logins. Treat the phone like the keys to the computer.
  • Port 7777 listens on your local network. Wrong passwords are throttled. Only allow the firewall on Private networks.
  • Internet access is optional and off by default.
