    Internet access

    Optional. Reach Pocket Dev from anywhere, not only your Wi-Fi.

    Pocket Dev works on your Wi-Fi without any of this. With internet access on, phones on the same Wi-Fi still have the Wi-Fi address and can switch between the two.

    cloudflared is not installed on this computer. In Terminal, run brew install cloudflared, then restart Pocket Dev and come back here.

    Only your Wi-Fi reaches Pocket Dev. Choose Quick link or My own domain to reach it from anywhere.

    Needs only cloudflared on this Mac, no account. Turn on gives a random trycloudflare.com address that lasts until you turn it off or Pocket Dev restarts. Every Turn on is a new address, so each phone links to it again from Wi-Fi (Settings → Connection → Link this phone) before it can open it without the password.

    Open
    1. In the Cloudflare dashboard, open Zero Trust → Networks → Tunnels → Create a tunnel → Cloudflared, and name it.
    2. From the install command it shows, copy only the token (the long code after --token). Do not run that command: Pocket Dev runs cloudflared for you.
    3. Add a public hostname, such as pocket.example.com, pointing to HTTP localhost:7777. The domain must use Cloudflare DNS.
    4. Turn on Always Use HTTPS for the domain (SSL/TLS → Edge Certificates), so a phone that types the address without https is sent there before it logs in.
    5. Paste the hostname and the token here.

    One fixed address, so each phone links to it once: on Wi-Fi, Settings → Connection → Link this phone. After that it opens the address without the password, even with Approve new devices on.

    Lockdown

    Disconnects phone access, logs out every device (including ones waiting for approval), stops every port forward, and cancels every login QR code. Blocked devices stay blocked. Terminals keep running on the Mac unless you tick the box. Phones get back in only after you press Connect; if the password leaked, change it in the same step.
